# Golden Crust Bakery - Frontend Client

This directory contains the Single Page Application (SPA) for the Golden Crust Bakery POS & Inventory System, built using **React 18**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Zustand**.

> **Note:** For full system architecture, backend documentation, API references, and deployment guides, please see the unified [Root README](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Setup environment variables
cp .env.example .env

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
